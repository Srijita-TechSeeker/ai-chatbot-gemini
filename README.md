# 🤖 MyChatBot

A modern, fast, and secure AI chatbot built with **Next.js 15**, **Tailwind CSS 4**, and the **Google Gemini API**.

🚀 **Live Demo:** [https://taupe-alpaca-53d7b5.netlify.app/](https://taupe-alpaca-53d7b5.netlify.app/)

---

## ✨ Features

- **AI-Powered:** Integrated with Google Gemini for intelligent, real-time responses.
- **Modern UI:** Styled with **Tailwind CSS 4** and **Radix UI** for a smooth, accessible experience.
- **Markdown Support:** Full support for code blocks, tables, and formatting via `react-markdown` and `remark-gfm`.
- **Responsive Design:** Optimized for mobile, tablet, and desktop screens.
- **Secure:** Patched against critical vulnerabilities (CVE-2025-55182) to ensure user safety.

## 🛠️ Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **AI Engine:** [Google Gemini API](https://ai.google.dev/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Components:** [Radix UI](https://www.radix-ui.com/)
- **Deployment:** [Netlify](https://www.netlify.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js 20+ 
- A Google Gemini API Key (Get one at [Google AI Studio](https://aistudio.google.com/))

### Installation

 **Clone the repository:**
   ```bash
   git clone [https://github.com/YOUR_USERNAME/mychatbot.git](https://github.com/YOUR_USERNAME/mychatbot.git)
   cd mychatbot
   Install dependencies:

Bash

npm install
Set up environment variables: Create a .env.local file in the root directory and add your key:

Code snippet

NEXT_PUBLIC_GEMINI_API_KEY1=your_api_key_here
Run the development server:

Bash

npm run dev
Open http://localhost:3000 to see the result.
